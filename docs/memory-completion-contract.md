## Shared card shape

Keep existing MemoryCard fields. Add nullable TEXT fields formula, roc, precautions, steps, initialConditions, finalConditions, chinese, english, letterType, paragraphPosition, sentenceFunction, clozeText, comparison. Store sentences as JSON array of strings and slots as JSON string map; expose sentences as string[] and slots as Record<string,string> in the DTO. Tags remain string[] in the DTO. DTO includes id/userId/courseId/chapterId/title/cardType/prompt/answer/explanation/conditions/pitfalls/source/notes/dueAt/lastReviewedAt/intervalDays/easeFactor/repetitions/lapses/suspended/createdAt/updatedAt, course:{id,name}, chapter:{id,name}|null, and optional latest review information. Never rewrite imported/user text or LaTeX. Validation may reject empty required text but never trim formula/answer/source content silently. Single card editor uses all named fields.

## Settings

StudySettings keyed userId, initialized once. dailyNewLimit default20, dailyReviewLimit default100, relearnMinutes10, initialGoodDays1, initialEasyDays4, hardMultiplier1.2, easyMultiplier1.3, maxIntervalDays365, examDate nullable ISO date, timezone Asia/Shanghai, theme system|light|dark, defaultsInitialized Boolean. Bound/range-validate everything. No repeated GET recreating deleted default courses. Course.examYear remains optional, course/chapter CRUD and ownership verified.

MemoryReview adds responseText nullable, clientEventId nullable with @@unique([userId,clientEventId]). Store observed reviewedAt, responseMs and mode. Idempotent retry returns existing event without changing scheduling again. Server validates event time and ownership, retains client event date appropriately for offline reviews. Rating again|hard|good|easy. All correctness statistics are explicitly self-assessed rather than automatic math-equivalence grading.

## API contract (JSON)

Existing /api/study/courses GET => Course[] with chapters and _count.cards. POST create. /courses/[id] PATCH edit, DELETE explicit UI confirmation and transaction. /courses/[id]/chapters POST. /chapters/[id] PATCH/DELETE. Deleting a chapter unassigns cards, deleting course/card cascades only its owned data.
/cards GET filters courseId/chapterId/search/cardType/tag/suspended/limit/offset, response remains CardDTO[]. POST create. /cards/[id] GET => CardDTO with reviews[], PATCH validated edit including dueAt and suspension, DELETE. /cards/[id]/copy POST resets review schedule and history, copies content exactly.
/review GET query mode due|mistakes|today-mistakes|random|all plus courseId/chapterId/cardType/examDate/limit. Returns CardDTO[]; due queue respects new/review limits and per-user timezone. Mistakes from latest/current failed state, not any historic failure forever. Stable tie-breaking. Random must actually randomize eligible scope. POST {cardId,rating,mode,responseText,responseMs,clientEventId,reviewedAt?} => {card:CardDTO,review:{id,clientEventId,nextDueAt},duplicate:boolean}; scheduler configurable and exam clamp. Offline events saved transactionally exactly once.
/settings GET/PATCH => Settings DTO.
/stats GET => {total,due,reviewsToday,accuracy,todayAccuracy,streak,forgettingRate,courses:[{id,name,count,mastery}],weakChapters:[{id,name,course,count,forgettingRate,mastery}],daily:[{date,reviews,successes,forgotten}],weakCards:[{id,title,course,chapter,consecutiveFailures,lapses}],todayNewUsed,todayReviewsUsed}. Graceful real empty states. daily/weekly stats based on records and timezone.
/import POST {action:'preview'|'commit',format:'csv'|'markdown'|'json',data:string,courseId?,mapping?:Record<canonicalField,inputColumn>,skipDuplicates?:boolean} => preview {headers,rows:TransferCard[],errors:[{row,field?,message}],warnings:[],duplicates:number,validCount}, commit {imported,skipped}. Must atomically validate all rows; no silent row drop. UI never commits until preview is confirmed. Preserve quotes/commas/newlines/LaTeX. Idempotent exact duplicate protection. preview supports mapping; backend uses pure transfer worker module.
/export GET format=json|csv|markdown with scope filters => attachment; must roundtrip all content including roc/conditions, no flattening newline. JSON content export vs full backup documented distinctly.
/backup GET => full user-owned JSON (schemaVersion:1,exportedAt,settings,courses/chapters/cards/reviews) excluding credentials/other users. POST {action:'preview'|'restore',data:string} => valid error preview or additive restore; no deletion of existing data, transactional id maps, scheduling/history preserved, duplicate protection and explicit UI restore confirmation. Do not touch live backups; parent handles production snapshots.
/samples GET => sample definitions from study-samples.ts; POST explicitly imports selected sample cards (isExample in notes/source), maps courses/chapters under user; no automatically seeded authority-labelled formulas.

## Pure module API (transfer worker owns)

study-transfer exports types TransferCard, TransferError, TransferPreview; parseStudyImport(data,format,mapping?) => {headers:string[],rows:TransferCard[],errors:TransferError[],warnings:string[],validCount:number}. TransferCard fields above plus course?,chapter?, tags array, sentences array,slots map. serializeStudyCards(cards,format) => string. CSV robust quoted multiline; markdown documented lossless fenced-json or field-block format and human front/back blocks. JSON string LaTeX roundtrip. Syntax checking flags dubious formula/cloze without modifying. Backend maps course/chapter after preview. Preview caps data size/card count.
study-training exports TRAINING_MODES (array objects {id,label}), buildTrainingTask(card,mode,slotValues?) => {prompt:string,expectedAnswer:string,items?:string[],pairs?:{left,right}[],kind:'text'|'cloze'|'order'|'compose'|'match',warnings:string[]}. Supported ids recall,zh-en,en-zh,formula,cloze,formula-cloze,condition-conclusion,conclusion-condition,compare,steps,paragraph,sentence-order,sentence-compose,template-match,transform,inverse-transform,roc,initial-final. Exact text/LaTeX preserved. Empty prerequisites yields warnings/disabled mode, never fake content. {{c1::text}} cloze explicit user markings; rendering before reveal blanks content without leaking via hidden DOM. slots syntax {{keyword}} explicit replace in task only, card not changed. sentence ordering match actual user-provided source sequence; compose combines selected source sentences; pairs constructed from provided card metadata only. Math self-assessment; English comparison is advisory not universal correctness.
study-samples exports DEFAULT_STUDY_COURSES (name,subjectKey,chapters[]), STUDY_EXAMPLES (TransferCard[] with verified source links/explanations, all labelled 示例). Chapters cover every topic in user's request. Small examples at least one per each five courses, not a pretend authoritative full formula bank.
